# UI显示范围

资料固定成功发布客户端版本，精确证据在私有忽略目录。16名角色正式服可获取范围由玩家确认。角色概览、技能描述/参数、校准、密录、服饰采用正常详情UI绑定；基础数值带等级和加成条件。诗凛缺少一个实际面板绑定的技能组暂不收录。

装备范围由正常背包套装筛选及套装详情预览确定，共31套124部件；预览不代表制造配方解锁。效果名严格沿用UI的技能消息优先规则，不用配置备注。仅显示固定主属性与UI可查看效果等级，不导出随机权重。道具为已核实资源货币和校准材料，共29条，非全道具表。

原生图片通过固定版本图片映射逐项核对；A级主视觉背景为用户提供的干净裁切实机场景，S级背景为依据固定版本灯光与发光差异AI编辑的Wiki素材，并非实机截图。原图和账号标识不会公开。普通UI显示的概率文案正常保留，隐藏概率不公开。


## 刻录、注射器、地图与装扮

仍使用同一固定发布提交与数据库版本，新增显示投影位于content/extra.json，构建以审核后摘要锁定；原始配置、ID、GUID和截图保存在忽略目录。

- 刻录：正常详情入口PopupCardDrawRecordView读取gachaDisplays.CheckDes；InventoryItem读取gachaPoolNotices的基础/综合概率。只收御能者招募、新手刻录、千幻万变，按UI显示百分比原样保留三位小数；不把客户端起止时间视为线上开放证据。
- 注射器：BloodBottleModel正常场景条目、BloodBottleDetail名称/使用次数/等级/图标；BloodBottleBuffHandler按强化等级渲染恢复效果，BloodIBottleLevelUp显示消耗。排除场景专用且无正常道具的记录，不输出恢复公式或技能内部参数。
- 地图：LargeMapView 的 WorldMapRoot/五个 AreaCell 作为地区入口；30张原生沙盘切片合成一张背景，热点按 EnterAreaMapBtn 根变换定位。AreaGrid 的 Bg/Room/Detail 合成五张地区底图，基础显示烘焙24个状态控制房间遮罩；正常探索可能解除这些遮罩，不将其认定为永久隐藏内容。公开20个子区域名称及UI位置，不导出原始切片、世界对象坐标或账号探索数据。
- 装扮：SubSkinView正常名字、说明和预览切换；原生CharacterSkin二维图由SkinItem/PopupCharacterSkinAcquireView同一皮肤标识绑定。默认装扮复用该角色已审核立绘，三套替换装扮使用对应原生图，不以其他角色代替。

角色结果背景集中在src/hero-backgrounds.js按S/A映射。A级使用已裁去标识的用户空场景；S级使用依据固定release的LightRoot_SSR与SR灯光/发光差异进行AI编辑的Wiki背景，并非S级实机截图；未把生成图当作游戏原生资源。

## 限定、获取途径与紧凑角色布局

- PopupCardDrawRecordView.CheckDes 正常规则文案明确永久池非限定、限定S不进入常驻；InventoryItem 绑定 gachaPoolNotices 的可见名单。UP 标记独立，不等同限定。正式实装日期缺证时不填造日期。
- CommonItemDetail.SetupObtainWaySources 的 JumpType/ItemJumpHelper 过滤决定来源显示；正常制造、活动、兑换、服饰商店与注射器解锁说明另按各自 UI 绑定。仅输出名称、条件、显示消耗和有效站内链接。尚未闭合的四类自选箱获取链不加入公开来源。
- SkilliconGroup 原生节点位置用于技能环；ElitistV3 的 ElitePointGroupV2.pointsList 与 EliteModel.GetPointData 对应3/6/9阶段、18个显示节点，保留同锚点分段关系。网页不模拟账号培养状态或提交操作。
- 默认等级取每组已审定等级的最大值，13级等额外上限仍显示对应密录条件，固定1级节点不扩展。装扮选择仅替换详情hero，预览失败回退默认立绘。

### 沙盘视觉还原修正

完整画布5120×3072；30张底图与enterAreaImageDic绑定的img_build1/2/3/4/6先在原尺寸合成，再缩小输出，避免合成库先缩放导致叠图错位。按钮锚定建筑中心，名牌/圆点随视口反向缩放；Normal/Show使用img_id/id2与img_point/point2原生图。MapFogBg静态前景文字按原RectTransform与透明度叠加。使用五地区地形参考，不模拟账号迷雾、探索度、任务或玩家位置。停用或未绑定的img_build5/7不启用，原始切片/区域遮罩不进入站点。

建筑贴图带原生地形，必须按每图自定义pivot（奥鲁姆0.89/0.84、纽特0.97/0.78、因弗内斯0.97/0.77、瓦尔肯0.68/0.80、巨坑底部0.78/0.99）定位后合成为一张底图。transform锚点与贴图矩形中心不同；透明点击层使用同一矩形，只有名牌按屏幕比例反缩放。不得在热点CSS、伪元素或单独地区图像再次绘制等高线背景。

五地区以外的地形已在合成底图中净化为原生board_worldmap网格：以四张正常地区mask的非零支撑范围及五个已批准建筑贴片矩形作为固定参考边界。此边界不模拟账号迷雾强度或解锁动画，原始mask不进入资产或产物。

沙盘地区入口只保留可键盘聚焦的原生热点，移除可见的重复地区索引收纳菜单。固定参考模式以地图下方单句短注说明。


## 地图点位与可探索通道

固定版本正常地图UI：LargeMapView 的宝箱保留标记、采集追踪、交互对象入口及NPC服务图标。网页以位置参考模式显示380处宝藏、449处采集物、36处时空裂隙入口、75处任务/服务NPC及149处Wiki补充挑战热点；采集物按均可采集处理，不读取账号状态。NPC包含有效、非隐藏普通世界任务关联的接受/交接位置及装备、注射器服务；排除未能证明任务范围或缺公开名称的记录。宝藏位置来自正常地图数据，按用户要求复用正常地图标记面板的闭合宝箱字形并着黄色；不声称它是游戏自动显示的未开启宝箱标记。采集物保持白色。

24处前景遮挡均匹配正式子世界普通状态对象。正常UI在对象状态离开初始状态时撤去遮挡；网页默认保留原生前景，眼睛按钮可显示可探索通道。原始地图切片、对象ID、世界坐标及任务条件配置不进入站点，仅公开同一图像坐标系的归一化位置。旧手动标记浏览器存储不再读取或写入，也不删除。

挑战热点使用正式探索与教程包装文案：岩茧103、机动战略·竞速26、机动战略·激斗10、机动战略·破障1、机动战略·清拆9，共149个独立入口。旧清单中的一个跑酷过程检查点已移除；坐标与其余条目键保持可追溯。玩法分类依据实际交互包装、蓝图或专用控制组件，并与正常教程标题、说明及教程图交叉核对。网页使用独立Wiki补充图例，不输出执行脚本、奖励权重或触发参数。坐标复用LargeMapView每地区原点、10倍比例、图标偏移与原生L0裁切；五地区416个原生点与正常世界对象位置交叉核对完全一致。

点位缩放聚合按类别及挑战正式类型分开，采用嵌套空间单元；放大仅拆分原分组。先按SVG实际视野筛选坐标，再生成锚点，避免可见点依附屏外图标。真正重叠的点位保留原位置，通过地图内浮层逐个选择。筛选区不再显示统计及其后的说明列表。

地图筛选现将岩茧和四种机动战略分别列为平级项目；NPC搜索仅匹配公开正式姓名，输入期间保留分类选择，清空恢复。旧挑战分类链接迁移到平级状态。宝箱和采集区单点信息仅保留名称，任务NPC及机动战略保留有用正文。

正式地图新增56处传输节点与13处监测塔，分别使用原生激活图标。传输节点的坐下位置及传送/补给链路对应椅子；监测塔名称取正常地图标题，教程称黑质密度监测塔。两类位置均来自同一正式地图注册数据、匹配正常子世界，并复用相同坐标变换。当前总计1158个参考点。

五地区各只有一张地形图；界面不再显示楼层装饰。子区域下拉仅提供真实跳转选项，占位不可选择；选择可由URL恢复，重置按钮恢复全图。

分类计数为整张地区地图公开参考点总数，不随隐藏区域模式、已勾类别、搜索或视口改变；仅地区总数为零的类别不提供选项。监测塔、传输节点优先，保留跨区选择偏好。

地图筛选数量为当前地区公开参考点总数，不随隐藏区域开关变化；仅地区总数为零的类型不显示。匹配点全部受前景遮挡时提示开启“显示隐藏区域”，不自动切换。

注射器强化材料：标题为强化等级与效果；材料图标和名称共用道具详情链接，数量单独展示。补充两种不同的稳定液及正式图标，内容仅来自固定版本材料预览和道具详情；Ⅰ型的物资兑换所来源已核对正常商店列表，一型暂无可证实的获取入口，不补造来源。

装备强化表加入当前级升下一级的熔锻晶体消耗：固定版EquipLevelUpView以目标xpItem.count减当前xpItem.count显示消耗，TableRule.GetLevelMaterialId按装备space与等级选表；满级无后续升级，显示破折号。移除培养与装备条件区块。

装备详情：表头与标题明确强化等级、固定属性和逐级熔锻晶体消耗；装备特性按原生EquipFeatureTab图标/名称/等级绑定标注，幻舞与专注均属特性，不推定套装属性。正常制造与获取消耗预览补充36个引用道具，仅导出名称、类型、品质、说明、图标及已证明的获取入口。获取途径条件内道具引用和消耗均链接到现有道具详情。

任务一览：任务组为目录单位、任务步骤为关系节点。当前投影55组508节点；入口锚定已公开正式地图NPC任务、注射器精确奖励及明确前置闭包。TaskListComponentV3过滤无效/隐藏任务；MissionConfig从mainmissionDatas取类型、从missionRGroups取奖励；TaskPanel只预览collections.Certain。页签采用TaskPanel.prefab的本地化页签：主线、支线、引导、同行。仅导出玩家标题/正文/地点、明确任务完成前置与NextMission链接、确定奖励名称数量及精确站内引用；不导出条件脚本或内部ID。未闭合关系不补造，非完整全游戏任务表。

任务复核：使用1.0.0_dev远端精确版本仅核对状态，不从dev新增正文；剔除1个已禁用节点，保留55组508节点。地点改按实际TaskPanel地图/子区域名称绑定，不使用遗留placeDesc字段。未证明正式可达的NPC相关字段暂不进入投影，原文与逐页结论保留私有记录。背景无损WebP与原PNG解码像素逐字节一致，恢复原40MiB预算，不重复打包PNG。卡池单项值仅依固定前端公示文案与唯一规则计算，内部权重不参与公开值。

任务节点地图位置来自固定release正常指引：EnterAreaCondition.OnTracing的显示位置、NPCMissionPoint的静态唯一NPC位置、节点AcceptAction的AddMissionMarkAction。复用已核对地图投影；不采用触发碰撞体偏移、不推断动态NPC路线，不导出原始世界坐标/内部标识。NPC提交条件按TableRule/NpcDataConfig的地区映射解析。遮挡位置遵守眼睛开关，任务标记与地图元素数量独立；任务直达不改变用户偏好。来源与排除原因保留于忽略目录。
